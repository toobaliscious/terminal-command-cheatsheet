02 Files

Create file

Linuxtouch ~/terminal-lab/demo.txt
CMDtype nul > "%TEMP%\terminal-lab\demo.txt"
PowerShellNew-Item -ItemType File -Force "$env:TEMP\terminal-lab\demo.txt"

02 Files

Write file

Linuxecho Hello > ~/terminal-lab/demo.txt
CMDecho Hello > "%TEMP%\terminal-lab\demo.txt"
PowerShellSet-Content "$env:TEMP\terminal-lab\demo.txt" "Hello"

> overwrites existing contents.

02 Files

Append file

Linuxecho Again >> ~/terminal-lab/demo.txt
CMDecho Again >> "%TEMP%\terminal-lab\demo.txt"
PowerShellAdd-Content "$env:TEMP\terminal-lab\demo.txt" "Again"

>> appends.

02 Files

Read file

Linuxcat ~/terminal-lab/demo.txt
CMDtype "%TEMP%\terminal-lab\demo.txt"
PowerShellGet-Content "$env:TEMP\terminal-lab\demo.txt"

02 Files

Copy file

Linuxcp ~/terminal-lab/demo.txt ~/terminal-lab/copy.txt

PowerShellCopy-Item "$env:TEMP\terminal-lab\demo.txt" "$env:TEMP\terminal-lab\copy.txt"

02 Files

Rename file

Linuxmv ~/terminal-lab/copy.txt ~/terminal-lab/renamed.txt
CMDren "%TEMP%\terminal-lab\copy.txt" renamed.txt
PowerShellRename-Item "$env:TEMP\terminal-lab\copy.txt" renamed.txt

Run after Copy file.

02 Files

Delete test file

Linuxrm -i ~/terminal-lab/renamed.txt
CMDdel /p "%TEMP%\terminal-lab\renamed.txt"
PowerShellRemove-Item "$env:TEMP\terminal-lab\renamed.txt" -Confirm

Run after Rename file; deletion may be permanent.

06 Text & pipelines

Ignore case

Linuxgrep -i hello ~/terminal-lab/demo.txt
CMDfindstr /i hello "%TEMP%\terminal-lab\demo.txt"
PowerShellSelect-String -Path "$env:TEMP\terminal-lab\demo.txt" -Pattern hello

PowerShell Select-String is case-insensitive by default.

06 Text & pipelines

First lines

Linuxhead -n 5 ~/terminal-lab/demo.txt
CMDmore "%TEMP%\terminal-lab\demo.txt"
PowerShellGet-Content "$env:TEMP\terminal-lab\demo.txt" -TotalCount 5

CMD more paginates rather than selecting 5 lines.

06 Text & pipelines

Linuxtail -n 5 ~/terminal-lab/demo.txt

06 Text & pipelines

PowerShellGet-Content "$env:TEMP\terminal-lab\demo.txt" -Wait -Tail 5
